# VisionPlay

VisionPlay is a project that uses Python, OpenCV, MediaPipe, and Pygame.

## Docker Image

The Docker image is available on Docker Hub.

**Docker Hub:** https://hub.docker.com/r/shravanip20/visionplay

### Pull the Image

```bash
docker pull shravanip20/visionplay:latest
```

### Run the Container

```bash
docker run --rm shravanip20/visionplay:latest
```

### Verification

Expected output:

```text
VisionPlay dependencies loaded successfully
```
